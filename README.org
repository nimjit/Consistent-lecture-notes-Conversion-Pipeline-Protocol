#+title: Consistent lecture notes — Conversion Pipeline & Protocol
#+startup: overview

A deterministic conversion pipeline and Org-mode schema for turning
heterogeneous open-source lecture notes (LaTeX, Jupyter Book, mdBook,
and Markdown) into a uniform Org-mode or Markdown file structure.

At this stage, this repository tracks only the conversion tooling,
protocol specification, and licence-auditing scripts. Converted course
trees are excluded via =.gitignore= until individual courses have been
cleaned, verified for free/open licensing, and checked for upstream
attribution.

* Repository layout

+ =protocol/= — Formal specification for directory layout, file naming,
  =:PROPERTIES:= frontmatter, section structure, and link conventions.

+ =scripts/convert/= — Modular converter package (=mathconv.py=,
  =provenance.py=, =assets.py=, =links.py=, =writer.py=) driven by Pandoc.

+ =scripts/ingest.sh= — Convert, lint, and index a single course.

+ =scripts/sync.sh= — Idempotently convert, lint, and index all courses
  in the workspace, skipping any that are already lint-clean.

+ =scripts/lint.py= — Validator enforcing the protocol rules across
  generated =.org= files.

+ =scripts/gen_courses_org.py= — Audits upstream =LICENSE*=, =COPYING*=,
  and metadata files to generate =courses.org= and manage =.gitignore=
  exclusions.

+ =scripts/gen_project_index.py= — Generates a local root =index.org=.

+ =TODO.org= — Open protocol and tooling tasks.

* Requirements

+ Python 3.10+
+ =pandoc= on =PATH=
+ =git=

* Workflow

Place an upstream repository under =<domain>/<course-slug>/source/=.

Convert and validate a single course:
#+begin_src bash
./scripts/ingest.sh
#+end_src

Or run across the whole workspace:
#+begin_src bash
./scripts/sync.sh
#+end_src

By default, Pandoc emits native Org LaTeX math into
=<course>/org-latex/= and sets =:MATH_FORMAT: latex=. Pass
=--math-format typst= to emit Typst math (=:MATH_FORMAT: typst=)
instead. This will then be stored =<course>/org-latex/=.
/Note that the Typst maths conversion is still WIP./
/Not everything will be converted correctly,/
/and it will require manual cleanup./

*Markdown conversion is currently not handled yet.*

* Licensing & provenance

Every conversion injects the upstream author/origin, repository URL, and
detected licence into each page's =:PROPERTIES:= drawer and the course's
=README.org= via =scripts/convert/provenance.py=.

=scripts/gen_courses_org.py= enforces a fail-closed Git export policy:

  =block-all= (current default) — ignores all course content trees
  (=source/=, =org-mode/=, =markdown/=) as well as local =courses.org=
  and =index.org= files so only the tooling and protocol are tracked.

  =free-only= — tracks courses with verified free/open licences (e.g.,
  CC BY, CC BY-SA, CC0, MIT, Apache-2.0, GPL) while continuing to block
  =CC BY-NC=, =CC BY-ND=, personal notes, and unverified sources.
